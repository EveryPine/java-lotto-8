## 기능 목록


### 로또 구입 금액 입력 기능
- 로또 구입 금액을 입력한다.
- 조건:
  - 1,000 이상 100,000,000 이하의 정수
  - 1,000 단위 정수
```
구입금액을 입력해 주세요.
8000
```
- 로또 구입 금액 예외 상황:
  - 입력이 1,000 미만이거나 100,000,000(1억) 초과인 경우
  - 입력이 1,000 으로 나누어 떨어지지 않는 경우


### 로또 번호 발행 및 출력 기능
- 로또 수량을 계산한다.
- 로또 수량만큼 로또 번호를 생성한다.
- 모든 발행된 로또 번호를 오름차순으로 출력한다.
  ```
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    [7, 11, 16, 35, 36, 44]
    [1, 8, 11, 31, 41, 42]
    [13, 14, 16, 38, 42, 45]
    [7, 11, 30, 40, 42, 43]
    [2, 13, 22, 32, 38, 45]
    [1, 3, 5, 14, 22, 45]
  ```


### 당첨 번호 입력 기능
- 당첨 번호를 입력한다. 번호는 쉼표(,)를 기준으로 구분한다.
```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```
- 당첨 번호 예외 상황:
    - 각 당첨 번호가 1 미만이거나 45 초과인 경우
    - 당첨 번호 개수가 6개가 아닌 경우
    - 중복되는 당첨 번호가 있는 경우


- 보너스 번호를 입력한다.
```
보너스 번호를 입력해 주세요.
7
```
- 보너스 번호 예외 상황:
  - 보너스 번호가 1 미만이거나 45 초과인 경우
  - 보너스 번호가 당첨 번호와 중복되는 경우


### 당첨 통계 생성 및 출력 기능
- 당첨 내역을 계산한다.
  - 당첨 기준
  
    |  등급  |         기준          |     상금 (원)      |
    |:----:|:-------------------:|:---------------:|
    |  1등  |      6개 번호 일치       |  2,000,000,000  |
    |  2등  |  5개 번호 + 보너스 번호 일치  |   30,000,000    |
    |  3등  |      5개 번호 일치       |    1,500,000    |
    |  4등  |      4개 번호 일치       |     50,000      |
    |  5등  |      3개 번호 일치       |      5,000      |
- 수익률을 계산한다.
  - 소수점 둘째 자리에서 반올림한다.
  - 수익률 공식 (단위: %)
  $$
    수익률 = \frac{당첨금 총액}{로또 구입 금액} \times 100
  $$
- 당첨 내역을 출력한다.
```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```
  - 수익률을 출력한다.
```
총 수익률은 62.5%입니다.
```
