# java-lotto-precourse

## 기능 구현 목록

1. 로또 구입 금액을 입력받는다.
    - 사용자가 로또 구입 금액을 입력한다.
    - 로또 구입 금액에 대한 사용자 입력을 검증한다. 조건은 다음과 같다.
        - 로또 구입 금액은 1,000 이상 100,000,000(1억) 이하의 정수만 허용한다.
        - 로또 구입 금액은 1,000 으로 나누어 떨어져야 한다.
    - 로또 구입 금액에 대한 사용자 입력이 조건을 위반하는 경우,`IllegalArgumentException`을 발생시킨다.
        - 입력이 `null`또는 빈 문자열인 경우
        - 입력이 숫자(`0-9`)로 이루어져 있지 않은 경우
        - 입력이 1,000 미만이거나 100,000,000(1억) 초과인 경우
        - 입력이 1,000 으로 나누어 떨어지지 않는 경우


2. 로또 번호를 출력한다.
    - 로또 수량을 계산한다.
    - 로또 수량 개수만큼 로또 번호를 생성한다.
    - 생성된 로또 번호를 모두 출력한다.


3. 보너스 번호가 포함된 당첨 번호를 입력받는다.
    - 사용자가 당첨 번호를 입력한다.
    - 당첨 번호에 대한 사용자 입력을 검증한다. 조건은 다음과 같다.
        - 구분자는 쉼표(`,`)만 허용한다.
        - 각 당첨 번호는 1 이상 45 이하의 정수만 허용한다.
        - 당첨 번호 개수는 6개여야 한다.
    - 당첨 번호에 대한 사용자 입력이 조건을 위반하는 경우,`IllegalArgumentException`을 발생시킨다.
        - 입력이 `null`이거나 빈 문자열인 경우
        - 입력이 숫자(`0-9`) 및 쉼표(`,`)로 이루어져 있지 않은 경우
        - 당첨 번호가 1 미만이거나 45 초과인 경우
        - 당첨 번호 개수가 6개가 아닌 경우
    - 사용자가 보너스 번호를 입력한다.
    - 보너스 번호에 대한 사용자 입력을 검증한다. 조건은 다음과 같다.
        - 보너스 번호는 1 이상 45 이하의 정수만 허용한다.
    - 보너스 번호에 대한 사용자 입력이 조건을 위반하는 경우,`IllegalArgumentException`을 발생시킨다.
        - 입력이`null`이거나 빈 문자열인 경우
        - 입력이 숫자(`0-9`)로 이루어져 있지 않은 경우
        - 보너스 번호가 1 미만이거나 45 초과인 경우


4. 당첨 통계를 출력한다.
    - 당첨 내역을 계산한다.
    - 수익률을 계산한다.
    - 당첨 내역을 출력한다.
    - 수익률을 출력한다.
